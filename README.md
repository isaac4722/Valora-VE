**ValoraVE** es una app Android nativa (Flutter/Dart puro) para conocer
cuánto vale tu dinero en Venezuela: tasas BCV y paralelo, conversor
multi-divisa (USD · VES · EUR · COP · BRL · MXN), lista de compras
compartida en vivo, libro de precios por producto, finanzas personales y
análisis de devaluación — todo offline-first, en tu teléfono.

> 🚧 **En construcción activa.** Este repo arrancó de cero (commit
> huérfano) para construir la versión nativa Flutter desde 0 con paridad
> 1:1 contra el spec funcional `MVP-CRUD.md`. El progreso por turnos de
> agentes vive en `progress.md` (documento interno).
